# Benchmark result summaries

`microbench-2026-09-15-summary.json` records the verified aggregate values from the full 480-cell QProver MicroBench run.

The raw reproducible output is generated by:

```bash
uv run qprover benchmark \
  --suite benchmarks/suite.json \
  --config benchmarks/config/full.json \
  --workspace . \
  --out /private/tmp/qprover-benchmark-full \
  --json

uv run qprover report \
  --input /private/tmp/qprover-benchmark-full \
  --suite benchmarks/suite.json \
  --config benchmarks/config/full.json \
  --labels benchmarks/labels.json \
  --json
```

Raw `runs.jsonl` and `scores.jsonl` are intentionally regenerated from the frozen suite/config rather than embedded as hand-edited fixtures. The committed summary must match the generated report before release.
