## Latest NaiveOracle diagnostic evidence

The latest v2 macro-free run before the v2.5 architecture change had:

- wall time about `2m27s` under the supplied run configuration;
- five concrete attempts;
- all five candidates had six actions;
- normalized `revert_step=N` feedback was present;
- spurious token-call callback annotations had been removed;
- `address(this)` was preserved in generated address parameters;
- the search still selected noisy auxiliary actions such as privileged-looking `mint` / `transferFrom` / `approve` paths and did not prove the supplied invariant false.

This evidence motivates property-directed relevance, state-local feasibility, short-horizon planning, contextual parameters, and persistent execution. It must not be encoded as a NaiveOracle-specific heuristic.
